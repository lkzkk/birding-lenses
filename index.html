What this page is for

This page helps visualise tradeoffs when choosing a camera and telephoto kit for wildlife and bird photography. The three main chart dimensions are total kit weight, equivalent aperture, and “reach” or 35mm-equivalent focal length. Filters define the candidate set; the plot shows the tradeoffs; the shortlist is for comparing finalists.

Scenario 1 · Lightest kit above a minimum reach

Starting from scratch (“greenfield”) and want the lightest kit with at least 500mm equivalent reach? Set the minimum reach to 500mm, then sort the table by Weight in ascending order. Active kits are kept ahead of filtered-out reference rows, so the first active row is the lightest kit meeting your filters.

Scenario 2 · Strong equivalent-aperture performance for the weight

Starting greenfield but targeting a particular reach? Narrow the reach range, then choose Equivalent aperture residual under Color. Greener points have a lower equivalent aperture than the regression predicts for their reach and weight.

Scenario 3 · Add a lens to a system you already own

Select only your current system under Brands, then set the reach you need. Sort by Equivalent aperture for the strongest light-gathering options or by Weight for the easiest kit to carry. Add two to four candidates to the shortlist for a direct comparison.

Scenario 4 · Maximum reach under a carrying limit

Set Maximum kit weight to the most you are willing to carry, then sort by Reach in descending order. Use Pareto-efficient only if you also want to remove candidates that are clearly dominated on reach, equivalent aperture, and weight.

Color & regression
Color Residuals A residual is the actual value minus the value predicted by a linear regression from the other two chart dimensions. By default the regression is fitted to the full dataset so a kit keeps the same residual when filters change. Positive reach residual means more reach than predicted. For equivalent aperture and weight, a negative residual is favorable.
Color scale

Average plane In a residual mode, the plane is the ordinary least-squares prediction surface for the selected metric from the other two dimensions. Every point on the plane has zero residual. Green marks the favorable residual direction.
