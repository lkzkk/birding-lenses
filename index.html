What this page is for

This page is meant to help visualise tradeoffs when choosing a camera and telephoto kit for wildlife and bird photography. Some of the main tradeoffs are total system weight, ability to gather light, and “reach” or 35mm-equivalent focal length. Use the filters to define the kits that could work for you, then use the plot and ranked table to compare the remaining tradeoffs.

Scenario 1 · Lightest kit above a minimum reach

Starting from scratch (“greenfield”) and want the lightest possible kit with at least 500mm equivalent reach? Set the minimum Reach range to 500mm, then sort the Ranked kits table by Weight in ascending order. The first row that is not greyed out is the lightest kit that meets those filters.

Scenario 2 · Best equivalent-aperture efficiency for the weight

Starting greenfield but targeting a particular reach? Narrow the Reach range around what you need. Under Visuals, choose Equivalent aperture residual as the color mode. The greenest points have a lower equivalent aperture than the regression predicts for their reach and weight—in other words, unusually strong light-gathering capability for that combination of reach and carrying weight.

Scenario 3 · Add a lens to a system you already own

If you already use one camera system and only want to choose another telephoto, select only that brand under Filters. Set the Reach range you need, then sort the table by Equivalent aperture for the strongest light-gathering options or by Weight for the easiest kit to carry. Add two to five candidates to the shortlist for a direct comparison.

Scenario 4 · Maximum reach under a carrying limit

Set Maximum kit weight to the most you are willing to carry, then sort Ranked kits by Eq. FL in descending order. The first non-greyed row gives the longest equivalent reach within that weight limit. Use Efficient only under Pareto filter if you want to remove clearly dominated tradeoffs first.

Reach range Equivalent focal length and equivalent aperture Equivalent focal length = actual focal length × crop factor. Equivalent aperture = actual f-number × crop factor. Equivalent aperture compares depth of field and total light at equivalent framing; it is not the f-number used for exposure. Fujifilm X APS-C uses the conventional 1.5× factor here. Color and regression
Color mode Residuals A residual is the actual value minus the value predicted by a linear regression from the other two chart dimensions. By default the regression is fitted to the full kit dataset, so a kit keeps the same residual when filters change. Enable “Recalculate residuals using filtered kits only” to refit the model to the currently active kits instead. Positive reach residual means more reach than predicted. For equivalent aperture and weight, a negative residual is favorable because the kit has a lower equivalent aperture or is lighter than predicted. Residuals describe trade-off efficiency, not overall image quality.

Average plane In a residual mode, the plane is the ordinary least-squares prediction surface for the selected metric from the other two dimensions. Every point on the plane has zero residual. Points on the favorable side perform better than the model expects for that combination of the other two dimensions; green always marks the favorable residual direction.
